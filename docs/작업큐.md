## 감정 친구 게임으로 키우기
게임의 방향: **감정 요정 친구를 만나고 모으는 게임**.
친구마다 감정이 하나 있고, 감정은 글자가 아니라 **색과 모양과 움직임**으로 보인다.

- [ ] `CHARACTERS` 에 `emotion` 필드 넣기 + 기존 요정 8명에 감정 하나씩 붙이기 (character-artist)
- [ ] 감정 요정 4명 추가 — 기쁨(노랑·통통 튐), 슬픔(파랑·처진 귀), 화남(빨강·뾰족 장식), 놀람(큰 눈) (character-artist)
- [ ] 친구 머리 위에 감정 아이콘 띄우기 (글자 아님, 도형으로) (gameplay-ui)
- [ ] 인사하면 그 친구 감정 색깔 하트 파티클이 터지게 (gameplay-ui)
- [ ] 친구 도감 — 책 아이콘 + 열고 닫기만 먼저 (gameplay-ui)
- [ ] 도감에 만난 친구 = 컬러 / 못 만난 친구 = 실루엣 + `?` (gameplay-ui)
- [ ] 만난 친구를 `localStorage` 에 저장 → `src/save.js` (gameplay-ui)
- [ ] 처음 만난 친구는 화면 가운데 "새 친구!" 2초 연출 (gameplay-ui)
- [ ] 감정별로 모이는 자리 만들기 — 기쁨 언덕, 방울 연못 (world-builder)
