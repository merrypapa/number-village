# 진행 상황

> Claude Code는 새 세션마다 이 파일을 먼저 읽고, **다음 Phase 하나만** 진행한 뒤
> 이 파일을 갱신하고 커밋한다.

## 현재 상태
- ✅ **Phase 0** 프로젝트 셋업, 씬·바닥·조명·하늘·구름
- ✅ **Phase 1** 플레이어 이동 + 3인칭 카메라 + 걷기 애니메이션
- ✅ **Phase 2 (부분)** 캐릭터 18종 팩토리 + 캐릭터 선택 화면
- ✅ **Phase 3 (기초)** 성 1채, 우리 집, 친구 집 6채, 나무 40그루, 분수
- ✅ **Phase 3 (충돌)** 나무·집·성·분수·놀이터에 부딪힘 처리 → `world.js`의 `collide()`
- ⬜ **Phase 3 (마무리)** 무지개 다리, 사탕 정원, 숫자 언덕, 울타리
- ✅ **Phase 4** NPC 24명 배회 + 이름표 + 인사/말풍선 → `src/npcs.js`
- ✅ **추가** 놀이터(미끄럼틀·그네·시소·모래밭) → `src/playground.js`
- ✅ **추가** 하늘을 헤엄치는 고래 3마리 + 구름 → `src/sky.js`
- ✅ **추가** 요정 친구(~핑) 리뉴얼 — 2등신 비율, 크고 반짝이는 눈, 요정 날개,
  이마 보석, 애니 테두리, 주변에 도는 반짝이. 캐릭터 파일을 4개로 분리
  → `character-parts.js` `character-block.js` `character-ping.js` `character-deco.js`
- ✅ **추가** 초코핑을 `imaes/char1.png` 그림 모습으로 다시 만듦 (**전용 뼈대**).
  아주 큰 머리 + 작은 몸 · 하얀 꽃잎 귀 · 층층이 튜튜 치마 · 구두. 날개와 꼬리는 없다.
  → `src/character-princess.js`
- ✅ **추가** 얼굴을 도형이 아니라 **Canvas 그림(텍스처)** 으로 그린다.
  눈동자 그라데이션 · 가는 속눈썹 · 눈썹 · 하트 코 · 웃는 입(이·혀) · 볼터치 · 이마 보석,
  그리고 가슴의 황금 하프 무늬까지 전부 그림이다 → `src/character-facetex.js`
- ✅ **추가** 머리카락을 곡선(TubeGeometry)으로 뽑는다. 끝이 뾰족하지 않고 **뭉툭하게 퍼지며**,
  정점 색으로 하늘색 → 분홍 그라데이션 + 결 무늬가 들어간다 → `character-parts.js`의 `makeStrand`
- ✅ **추가** 그림 닮게 만들기 2차 — 얼굴 **명암을 캔버스에 같이 그려서** 입체감을 냈고,
  얼굴을 계란형으로 눌렀으며(`faceShape`), 귀를 꽃잎 도형으로, 티아라를 구슬 세공으로,
  치마를 3층 물결 밑단으로, 자세를 살짝 비대칭으로 바꿨다.
- ✅ **추가** 스튜디오 반사광(환경맵) → `src/environment.js`.
  `scene.environment`는 MeshStandard/Physical에만 적용돼서 **다른 친구들은 영향 없음**.
- ✅ **고침** 얼굴이 무섭게 보이던 문제 — 눈·코·입이 얼굴 위쪽 21%에 몰려 있어 턱이 길었다.
  눈높이를 얼굴 세로 **49%**로 내리고(`character-facedraw.js`의 `CY`), 앞머리를 위로 올려
  이마를 넓혔으며, 입을 크게, 속눈썹을 얇고 밝게, 살결을 창백하게 바꿨다.
- ⬜ **Phase 5** 친구 도감 + localStorage 저장 + 감정표현 → `src/ui.js`, `src/save.js`
- ⬜ **Phase 6** 사운드, 모바일 가상 조이스틱, 성능 최적화, 배포
- ⬜ **Phase 7** (선택) 실제 멀티플레이

## 알려진 이슈 / 다음에 손볼 것
- 모바일 가상 조이스틱 미구현 (`player.js`의 `joy` 객체에 연결만 하면 됨)
- 친구 도감이 아직 없어서 만난 친구가 저장되지 않음 → Phase 5에서 처리
- 미끄럼판·그네는 보기만 하는 것. 실제로 타는 동작은 아직 없음
- 고래 높이(`sky.js`의 `WHALE_HEIGHT`)를 너무 올리면 카메라 화면 위로 벗어난다.
  올리려면 `player.js`의 `LOOK_HEIGHT`도 같이 올려야 한다.
- 마을 NPC는 가볍게 그리려고 `createCharacter(def, 'simple')`을 쓴다.
  테두리·속눈썹·반짝이·아랫날개가 빠진다. 전부 보고 싶으면 `'full'`로 바꾸면 되지만
  NPC 24명이면 조금 느려질 수 있다.

## 고친 것
- 캐릭터 선택 화면 카메라가 너무 멀어서 요정이 작게 보이던 것 (`main.js`의 `sCam`)
- 반투명 날개·테두리·반짝이가 그림자를 만들던 것 (`userData.noShadow` 표시로 제외)
- 방향키 방향이 카메라와 반대로 나가던 버그 수정 (`player.js`의 이동 방향 계산)
  → 이제 위 화살표 = 화면 안쪽, 오른쪽 화살표 = 화면 오른쪽

- 캐릭터 뼈대는 `characters.js` 맨 위 `BUILDERS`에서 `type` 값으로 고른다.
  `block`(숫자블록) · `ping`(요정) · `princess`(얼음공주 요정).
  새 뼈대를 만들려면 파일 하나 만들고 `BUILDERS`에 한 줄 추가하면 된다.
- 초코핑 값은 전부 `characters.js`의 그 한 줄에 있다 (머리색·눈 색·치마색 등).
  크기와 자세는 `character-princess.js` 맨 위 상수에서 바꾼다.
- **얼굴을 고치고 싶으면** `character-facetex.js` 맨 위 숫자를 바꾼다.
  `EYE_X`(눈 사이) `EYE_RX/EYE_RY`(눈 크기) `MOUTH_Y`(입 높이) `GEM_Y`(보석 높이) 등.
  그림은 1024×1024 캔버스이고 한가운데(512,512)가 얼굴 정중앙이다.
- **머리카락 모양**은 `character-princess.js`의 `LOCKS` 배열이다.
  `pts`가 머리카락이 지나갈 점들, `r0`은 뿌리 굵기, `r1`은 끝 굵기(크게 하면 더 퍼진다).
- 초코핑만 `MeshPhysicalMaterial`(반질반질)을 쓴다. 다른 친구는 예전 만화풍 그대로다.
