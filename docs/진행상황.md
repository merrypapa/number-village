# 진행 상황

> Claude Code는 새 세션마다 이 파일을 먼저 읽고, **다음 Phase 하나만** 진행한 뒤
> 이 파일을 갱신하고 커밋한다.

  귀는 동그란 하얀 뭉치, 치마는 물결 없이 매끈한 종 모양, 팔은 짧게 옆으로.

  → `assets/models/sappun.glb` (`id`도 `choco` → `sappun`)
  코드로 도형을 쌓아 만들던 방식을 그만두고, 만든 모델을 그대로 불러온다.

    `npx @gltf-transform/cli@4 optimize 원본.glb 결과.glb --texture-compress false --compress quantize --simplify true --simplify-ratio 0.02 --simplify-error 0.005`
    그다음 `... resize 결과.glb 최종.glb --width 1024 --height 1024`
    (삼각형 195만 → 3.9만, 텍스처 2048 → 1024)
  - **뼈대(뼈·관절)가 없는 모델이라** 팔다리를 따로 못 움직인다. 대신 몸 전체를
    통통 튀기고 갸웃거리게 했다 → `character-model.js`의 `HOP` `FLOAT` `TILT`
  - 예전 코드 도형 버전은 `characters.js`에 주석으로 남겨뒀다. 비교해보고 싶으면 살리면 된다

  - 삼각형 5,900~18,200개. 사뿐핑만 38,994로 좀 많다 (먼저 만든 거라 설정이 달랐다)

  - 땅에 있을 때만 뛴다 (공중 2단 점프 없음). 최고 약 1.5칸

- ✅ **추가** 놀이터에서 **그네·미끄럼틀·시소를 진짜로 탄다** → `src/rides.js`
  - 놀이기구 옆에 가면 오른쪽에 노란 **🎠 타기 버튼**이 나타난다 (키보드는 **E**)
  - **그네**: 의자에 올라타면 몸이 그네를 따라 기울고, 누가 타면 **더 크게** 흔들린다
    (`playground.js`의 `SWING_RIDE_AMP`). **내리기**를 누를 때까지 계속 탄다
  - **미끄럼틀**: 사다리 오르기 → 발판 건너기 → 슝(점점 빨라진다) → 폴짝, 전부 자동.
    다 내려오면 저절로 내린다 (`autoEnd:true`)
  - **시소**: 앞뒤로 **자리가 2개**다. 아이가 한쪽에 타면 마을 친구가 반대쪽에 와서
    **마주 보고** 탄다. 한쪽이 올라가면 반대쪽은 내려간다. 누가 타면 더 크게
    오르내린다 (`SEESAW_RIDE_AMP`)
  - **마을 친구(NPC)들도 스스로 놀러 온다.** 쉬고 나서 `RIDE_CHANCE`(0.4) 확률로
    빈 놀이기구를 골라 걸어가서 타고 논다 → `npcs.js`
    자리를 미리 맡아두기 때문에 한 그네에 두 명이 겹치지 않는다
  - 자리는 모두 **5개** (그네 2 + 미끄럼틀 1 + 시소 2)
  - 놀이기구 하나는 `{ kind, label, enter, exit, duration, autoEnd, rider, pose() }`
    모양이면 된다. **`playground.js`에 하나 더 밀어 넣으면 새 놀이기구도 바로 탈 수 있다**
    (`makeSwingRide` / `makeSlideRide` / `makeSeesawRide`를 흉내 내면 된다)
  - 캐릭터에 뼈대(관절)가 없어서 "앉는" 자세는 못 만든다. 의자 위에 **올라선 채**
    몸 전체가 기우는 방식이다
  - 이것 때문에 놀이기구 크기를 키웠다:
    미끄럼틀 지붕(가장 큰 친구 열이, 키 3.1이 발판에 서도 안 닿게)과
    그네 가로대(`BAR_Y` 3.4 → 4.6, 줄도 같이 길어짐). 시소는 위에 걸리는 게 없어서 그대로다

- ✅ **추가** 🏰 **성 안으로 들어간다** — 성 정문 앞에 서면 새로운 공간이 펼쳐진다
  → `src/castle-interior.js` (방·조명·문·타기), `src/castle-props.js` (가구)
  - **공간(area)** 이라는 개념이 생겼다. 공간 하나는 이런 모양이다:
    `{ scene, spawn, yaw, collide, isBlocked, update, rides, doors }`
    마을(`world.js`)도 성 안(`castle-interior.js`)도 똑같은 모양이라서
    `player.js`와 `npcs.js`는 어느 공간에 있든 그대로 동작한다.
    **새 공간(예: 사탕 가게, 지하 보물창고)을 만들려면 이 모양으로 하나 더 만들면 된다.**

    화면이 잠깐 하얘졌다가(`#fade`) 다른 공간으로 넘어간다 → `main.js`의 `goThroughDoor`
    한 번 문에서 멀어져야 다시 들어가진다(문 앞에서 무한 반복 방지)
  - 성 안은 **처음 들어갈 때 한 번만** 만든다 (처음 로딩을 느리게 하지 않으려고)
  - 성 안 물건: 왕좌·벽난로(불이 흔들린다)·케이크 탁자·책장·곰인형 독서 자리·
    숫자 블록 장난감·흔들목마·풍선·화분·촛대·스테인드글라스 창·샹들리에 별·떠다니는 반짝이
  - **왕좌에 앉기 👑 / 흔들목마 타기 🐴** — 놀이터와 똑같은 `rides.js`를 쓴다.
    성 안 친구 5명도 스스로 왕좌에 앉으러 온다
  - 바닥(체크무늬)·벽지(분홍 허리띠+하트)·스테인드글라스는 전부 **Canvas 그림**이다

  - 마을 쪽에는 **성 입구 표시**(분홍+금색 융단, 등불 4개, 문 위 하트)를 만들었고,

- 캐릭터 선택 화면 카메라가 너무 멀어서 요정이 작게 보이던 것 (`main.js`의 `sCam`)

- **.glb 압축 절차** (아빠 PC ↔ Claude 세션 분담):
  1. 아빠 PC (cmd): `chcp 65001` 후
     `for %f in (*.glb) do npx --yes @gltf-transform/cli@4 optimize "%f" "out\%~nf.glb" --texture-compress false --compress quantize --simplify true --simplify-ratio 0.007 --simplify-error 0.01`
     → 삼각형 약 1만 개, 파일 3~7MB
  2. GitHub 업로드 (웹 업로드는 **파일당 25MB, 한 번에 올리는 총량도 제한**이 있어 2~3개씩 나눈다)
  3. Claude 세션: `resize ... --width 512 --height 512` → 0.3~0.7MB
     (아빠 PC에서는 텍스처 명령이 `colourspace: parameter space not set`으로 실패한다. sharp 버그)
- **성능 기준**: 마을 NPC가 24명(`npcs.js`의 `NPC_COUNT`)이라 캐릭터 하나의 부담이 24배가 된다.
  캐릭터당 **삼각형 1만~1.5만 · 텍스처 512px · 0.5MB 이하**를 지킬 것.
  느려지면 `NPC_COUNT`를 16쯤으로 낮추는 게 가장 효과가 크다.
- **모델이 안 보이면** 브라우저 콘솔에 "모델을 불러오지 못했어요"가 찍힌다.

  2. 브라우저에서 `http://localhost:3000/tools/thumbs.html`
  3. 다 그려지면 "전부 내려받기" → 받은 파일을 `assets/thumbs/`에 넣기
  (안 해도 게임은 돌아간다. 색 카드로 나올 뿐이다.)
- **격자 카드가 서로 겹치면** `index.html`의 `.card` 높이 방식을 확인할 것.
  `aspect-ratio`는 격자 행 높이 계산이 어긋나는 경우가 있어서
  `height:0; padding-top:133.33%` 방식을 쓴다. 이걸 바꾸면 카드가 겹친다.
- **좁은 화면용 크기 조정**(`@media (max-width:520px)`)은 `<style>` **맨 끝**에 있어야 한다.
  앞쪽에 두면 뒤에 오는 규칙에 밀려서 적용이 안 된다.

## 🏘 마을 넓히기 (2026-09 작업)
아이가 부탁한 세 가지를 Step으로 나눠서 하나씩 만든다.
- ✅ **Step 1** 🛒 마트(편의점)
- ✅ **Step 2** 🏠 친구 집에 들어가기 (집주인 + 다리미 집)
- ⬜ **Step 3** 🎨 그림의 집 (그림 그리기 놀이)

### Step 1 — 🛒 행복마트
- 마을 북서쪽(-19, -17)에 마트 건물이 생겼다. 문 앞에 서면 안으로 들어간다
- 안에는 **진열대 3줄**(라면·통조림 / 과자·사탕 / 음료·주스), **벽면 음료 냉장고**,
  **아이스크림 냉동고**, **과일·채소 매대**, **계산대**(포스·스캐너·봉투·사탕 진열),
  **장바구니 더미**와 **카트**가 있다
- 진열대 앞에서 노란 버튼 **담기**를 누르면 물건이 바구니에 들어가고,
  **계산대**에서 **계산**을 누르면 "삐빅! 몇 개 계산 완료"가 뜬다
- **점원 뽀득핑**이 계산대 뒤에 서 있다. 손님 친구 3명이 통로를 돌아다닌다

#### 이때 같이 만든 공통 뼈대 (다음 Step에서 그대로 쓴다)
- `src/collide.js` — 부딪히기(충돌). world.js에서 떼어냈다. 모든 공간이 같이 쓴다
- `src/interior.js` — **실내 공간 만들기 도우미**. 바닥·벽·천장·나가는 문·조명을
  한 번에 만들어 준다. `makeInterior({w, d, h, …})` → `place()` `hang()` `addSpot()`
  → `finish()` 하면 main.js가 아는 "공간(area)"이 나온다
- `src/korean.js` — '을/를', '이/가' 조사 붙이기
- **문(door)에 `build(ctx)`를 적으면 그 공간을 그때 만든다** (world.js의 doors).
  집이 여러 채여도 main.js는 고치지 않아도 된다
- **`area.residents`** = 그 공간에 사는 친구들. `{ id, x, z, yaw, stay:true }`.
  `stay`를 켜면 걸어 다니지 않고 자기 자리에 서 있는다 (집주인·점원)
- **`spot.verb` / `spot.use(toast)`** = 노란 버튼에 뜰 글씨와 눌렀을 때 할 일.
  이걸로 담기·계산·그리기를 만든다

### Step 2 — 🏠 친구 집 6채
- 광장 둘레의 친구 집 6채가 **전부 들어갈 수 있게** 되었다.
  집은 조금 커졌고(8×5×8), **문이 환하게 빛나며**, 문 위에 이름표가 붙었다.
  집이 전부 **광장 쪽을 바라보도록** 방향도 고쳤다 (예전에는 바깥을 보고 있었다)
- 집 안(24×20)에는 거실(소파·탁자·TV·러그·스탠드), 부엌(싱크대·냉장고·식탁),
  침대, 창문·액자·벽시계가 있다. **집마다 다른 특별한 코너**가 하나씩 있다
- 할 수 있는 것: **앉기**(소파) · **잠자기**(침대) · **TV켜기** · 코너마다 다른 놀이
- **집주인이 산다.** 거실에 서서 반겨주고, 👋로 인사하면 말풍선이 뜬다

| 집 | 집주인 | 코너 | 버튼 |
|---|---|---|---|
| 다리미 집 | 실크핑 | 다리미판·다리미·빨래바구니·옷걸이·세탁기 | 다리미 |
| 요리하는 집 | 차차핑 | 냄비·도마·채소 | 요리 |
| 음악 집 | 악동핑 | 피아노·의자·악보 | 피아노 |
| 책 읽는 집 | 똑똑핑 | 책장·방석 | 책읽기 |
| 간식 집 | 꾸래핑 | 케이크 탁자 | 먹기 |
| 장난감 집 | 아자핑 | 장난감 상자·블록·공·곰인형 | 놀기 |

- 새 파일: `src/houses.js`(집 목록 + 집 한 채 만들기),
  `src/house-props.js`(가구), `src/house-theme.js`(코너)
- **집을 하나 더 늘리려면** `houses.js`의 `HOUSES`에 한 줄, `world.js`의
  `FRIEND_HOUSES`에 각도 하나를 추가하면 된다
- `castle-rides.js`의 `makeBedRide(bed, x, z, floorY, scale)`에
  **층 높이와 크기 배수**를 넘길 수 있게 고쳤다 (성 2층 침대 / 집 1층 작은 침대)
- 벽에 붙는 납작한 물건(창문·액자·시계)은 **그림자를 만들지 않는다**
  (`house-props.js`의 `flat()`). 안 그러면 비스듬한 얼룩이 생긴다

### 새 건물을 하나 더 넣으려면
1. `src/village-buildings.js`에 겉모습을 만든다 (`makeXxxBuilding()`)
2. `src/xxx.js`에 안쪽을 만든다 (`makeInterior` → `finish`)
3. `src/world.js`에 건물을 놓고 `doors`에 한 줄 추가한다 (`build: (ctx) => buildXxx(...)`)
→ main.js·player.js·npcs.js는 **고치지 않는다**

## 성 안 구조 (고칠 때 보는 지도)
```
        북(-z)                       치수: x -34~34, z -42~42, 천장 19, 2층 바닥 7.5
    ┌───────────────────────────┐
    │        👑 왕좌의 방        │  z -42 ~ -18  (2층 없음 · 천장까지 뻥 뚫림)
    ├────┬─────────────────┬────┤
    │요정 │                 │ 계단│  z -18 ~ 14
    │진열 │   🎪 중앙 홀     │ 회랑│  (가운데 홀도 뻥 뚫림 → 2층에서 내려다본다)
    │ 대  │                 │    │
    ├────┴───┬────────┬────┴────┤
    │ 📚도서관 │ 🚪현관  │ 🍰파티방 │  z 14 ~ 42
    └────────┴────────┴─────────┘
        남(+z) — 현관으로 나가면 마을
```
- **2층 = 위 그림의 바깥 "ㄷ자"** (서쪽 팔 = 보물방 · 동쪽 팔 = 계단참·발코니 ·
  남쪽 블록 = 공주 침실 + 별 전망대). 숫자는 `castle-layout.js`의 `SLAB` `STAIR` `HOLE`.
- **방을 넓히려면** `castle-layout.js` 맨 위의 `HALF_X` `HALF_Z`를 키우고,
  `SLAB`의 네모 좌표도 같이 고친다.
- **물건을 옮기려면** `castle-interior.js`의 `place(모양, x, z, 방향, 부딪힘, 높이)`
  줄만 고치면 된다. 2층에 놓을 때는 마지막에 `FLOOR2`를 넣는다.
- **성 안에서 할 수 있는 것**(앉기·타기·잠자기·공부하기)은 `src/castle-rides.js`에 모아뒀다.
  하나 추가하려면 `{ enter, enterY, pose(t,o), verb, offVerb }`를 만들어
  `castle-interior.js`의 `rides` 배열에 넣으면 된다.
  - `verb` / `offVerb` = 노란 버튼에 뜰 글씨 (없으면 '타기'/'내리기')
  - `enterY` = 그 놀이기구가 있는 층 높이 (2층이면 `FLOOR2`).
    이걸 적어야 1층에서 2층 미끄럼틀을 붙잡는 일이 없다
  - `parts` = 화면에 같이 넣을 것 (떠오르는 Z·숫자)
  - `tick(t, dt)` = 매 프레임 할 일 (왕관 내려오기, 이불 덮기)
