# 숫자마을 대모험 (Number Village) — 게임 기획안

> 7세 아이와 아빠가 함께 만드는 3D 브라우저 탐험 게임
> 이 문서는 Claude Code가 개발할 때 참조하는 단일 기준 문서입니다.

---

## 1. 한 줄 요약

아이가 좋아하는 캐릭터 중 하나를 골라, 파스텔 톤 성이 있는 예쁜 마을을
자유롭게 뛰어다니며 친구 캐릭터들을 만나고 모으는 3D 게임.

## 2. 목표와 제약

### 플레이어
- 주 플레이어: 7세 남아 (한글을 조금 읽음, 로블록스 계열 3D 게임 경험 있음)
- 보조 플레이어: 아빠 (같이 앉아서 플레이, 기능 추가 요청을 받는 사람)

### 절대 원칙 (모든 기능 결정의 기준)
1. **실패가 없다.** 죽음, 체력, 게임오버, 시간 제한 없음. 떨어져도 마을로 되돌아옴.
2. **글자는 최소.** 7세가 못 읽으면 없는 기능이다. 아이콘 + 큰 글씨 + 한 줄 이하.
3. **조작은 하나만 외우면 된다.** 이동 + `스페이스`(인사/말걸기). 그게 전부.
4. **3분 안에 재밌어야 한다.** 시작 → 캐릭터 고르기 → 바로 마을. 튜토리얼 없음.
5. **예뻐야 한다.** 파스텔, 둥근 형태, 밝은 하늘. 어둡거나 무서운 것 금지.
6. **부드러워야 한다.** 노트북/태블릿에서 60fps. 무거우면 기능을 뺀다.

### 기술 제약
- 브라우저에서 바로 실행. **빌드 단계 없음** (ES Modules + importmap).
- 외부 3D 모델 파일(.glb 등) 사용 금지. **모든 캐릭터/건물은 Three.js 기본 도형으로 코드에서 생성.**
  → 다운로드 없음, 로딩 없음, 라이선스 문제 없음, 아이가 색만 바꿔도 새 캐릭터가 생김.
- 저작권: 실제 방영 중인 애니메이션의 캐릭터 이름/디자인을 그대로 쓰지 않는다.
  숫자 블록 친구들 / `~핑` 계열 요정 친구들이라는 **컨셉만 빌리고 이름·디자인은 오리지널**로 만든다.
  (아이한테는 "우리가 만든 우리 캐릭터"가 훨씬 재밌는 포인트이기도 함)

## 3. "MMORPG 느낌"에 대한 결정

아이가 원하는 건 실제 온라인 접속이 아니라 **"큰 세계에 캐릭터들이 잔뜩 돌아다니는 느낌"**입니다.
따라서 v1은 **싱글플레이 + 30명의 NPC 친구**로 그 느낌을 만듭니다.

MMO처럼 보이게 하는 요소:
- NPC 친구 20~30명이 마을을 실제로 걸어다님 (제자리 서 있기 금지)
- 모든 캐릭터 머리 위에 이름표
- 가끔 말풍선이 떠오름 ("안녕!", "같이 놀자~")
- 가까이 가면 손을 흔들거나 폴짝 뜀
- 인사하면 친구 도감에 등록됨

실제 멀티플레이(아빠와 아들이 다른 기기에서 접속)는 **Phase 7의 선택 항목**입니다.
v1~v6이 다 끝나기 전에는 손대지 않습니다.

## 4. 게임 구조

### 화면 흐름
```
[타이틀] → [캐릭터 선택] → [마을 (메인 플레이)] ⇄ [친구 도감]
                                    ⇅
                                [우리 집 내부]
```

### 캐릭터 선택 화면
- 3D로 회전하는 캐릭터가 가운데. 좌우 큰 화살표 버튼으로 넘김.
- 캐릭터 이름 + 큰 "이 친구로 놀기!" 버튼
- 최소 16종 이상. 선택한 캐릭터는 마을에서 플레이어가 됨.
- 고르지 않은 캐릭터들은 NPC로 마을에 등장한다 (중요: 선택 화면과 NPC가 같은 데이터를 쓴다)

### 캐릭터 종류

**A. 숫자블록 친구 (10종)** — 큐브를 숫자만큼 쌓은 몸, 큰 눈, 짧은 팔다리
| 번호 | 이름 | 색 |
|---|---|---|
| 1 | 하나 | 빨강 |
| 2 | 두리 | 주황 |
| 3 | 세모 | 노랑 |
| 4 | 네모 | 초록 |
| 5 | 오공 | 하늘 |
| 6 | 육이 | 파랑 |
| 7 | 칠보 | 보라 |
| 8 | 팔팔 | 분홍 |
| 9 | 구름 | 민트 |
| 10 | 열이 | 무지개 |

**B. 요정 친구 `~핑` (8종)** — 둥근 몸통, 큰 눈, 귀, 꼬리, 머리 장식
| 이름 | 색 | 장식 |
|---|---|---|
| 반짝핑 | 연분홍 | 별 |
| 몽글핑 | 라벤더 | 하트 |
| 방울핑 | 하늘 | 물방울 |
| 초코핑 | 갈색 | 리본 |
| 살랑핑 | 연두 | 잎사귀 |
| 뽀글핑 | 크림 | 왕관 |
| 별밤핑 | 남색 | 달 |
| 무지핑 | 무지개 | 별 |

> 캐릭터 추가는 `src/characters.js`의 배열에 한 줄 추가하면 끝나야 한다.
> 아이가 "이름은 ○○, 색깔은 보라!"라고 하면 30초 안에 추가할 수 있어야 함.

### 마을 구성
| 장소 | 설명 |
|---|---|
| 중앙 광장 | 분수, 벤치, 캐릭터들이 가장 많이 모이는 곳. 스폰 지점 |
| 파스텔 성 | 마을의 랜드마크. 탑 4개 + 원뿔 지붕 + 깃발. 안에 들어갈 수 있으면 더 좋음 |
| 우리 집 | 플레이어의 집. 문에 다가가면 내부로 이동 |
| 친구들 집 | 색이 다른 작은 집 6~8채 |
| 무지개 다리 | 개울을 건너는 반원 다리 |
| 사탕 정원 | 알록달록 나무, 버섯 |
| 숫자 언덕 | 큰 숫자 조형물이 서 있는 낮은 언덕 |

- 맵 경계는 보이지 않는 벽이 아니라 **울타리와 나무**로 자연스럽게 막는다.
- 하늘: 하늘색 그라데이션 + 흰 구름 몇 개 (천천히 흐름).

### 조작
| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (카메라 기준) |
| 마우스 드래그 / 화면 드래그 | 카메라 회전 |
| Space / 화면의 큰 하트 버튼 | 인사하기 (가까운 친구에게 말 걸기) |
| Shift | 빠르게 달리기 |
| 모바일 | 왼쪽 가상 조이스틱 + 오른쪽 하트 버튼 |

- 카메라는 3인칭 추적. 손을 안 대도 진행 방향으로 부드럽게 정렬된다. (7세는 카메라 조작을 못 한다)
- 점프 넣지 말 것. 로블록스 습관 때문에 아이가 계속 점프하다가 목적을 잊음. → v2에서 재검토.

### 상호작용
- 친구에게 가까이 가면 머리 위에 `!` 아이콘
- 스페이스 → 말풍선 대사 + 친구 도감 등록 + "짤랑" 효과음 + 하트 파티클
- 처음 만난 친구는 화면 가운데 "새 친구!" 연출 (2초)

### 친구 도감
- 화면 우측 상단 책 아이콘
- 만난 친구 = 컬러 + 이름 / 아직 못 만난 친구 = 실루엣 + `?`
- "18명 중 7명" 큰 숫자로 진행도 표시
- 저장은 `localStorage` (계정/로그인 없음)

## 5. 개발 단계 (Phase)

한 Phase = Claude Code 한 세션. 각 Phase 끝에는 **반드시 브라우저에서 실행 가능**해야 합니다.
아이한테 매번 보여주는 게 목적이므로, "다음 단계에서 완성됩니다"는 없습니다.

| Phase | 내용 | 아이에게 보여줄 것 |
|---|---|---|
| 0 | 프로젝트 셋업, 씬·바닥·조명·하늘, 회전하는 큐브 | "화면에 3D가 나왔다!" |
| 1 | 플레이어 캐릭터 1종 + 이동 + 3인칭 카메라 + 걷기 애니메이션 | "내가 움직인다!" |
| 2 | 캐릭터 팩토리(18종) + 캐릭터 선택 화면 | "캐릭터를 고를 수 있다!" |
| 3 | 마을 건설: 성, 집, 나무, 광장, 다리, 울타리 | "성이 있다!" |
| 4 | NPC 20~30명 배회 + 이름표 + 인사/말풍선 | "친구들이 있다!" |
| 5 | 친구 도감 + 저장 + 감정표현(춤추기/손흔들기) | "친구를 모은다!" |
| 6 | 사운드, 모바일 터치, 성능 최적화, 배포 | "태블릿으로 논다!" |
| 7 | (선택) 실제 멀티플레이 | "아빠랑 같이 접속!" |

## 6. 성능 목표
- 노트북 60fps / 태블릿 30fps 이상
- draw call 200 이하 — 같은 나무/집은 `InstancedMesh` 또는 geometry 재사용
- 그림자는 캐릭터와 주요 건물만. 나무는 그림자 끄기
- NPC는 거리 기준 업데이트 스킵 (멀면 애니메이션 정지)

## 7. 만들지 않는 것 (v1 범위 밖)
- 전투, 체력, 죽음
- 채팅 입력창 (7세가 타이핑 못 함 + 안전 문제)
- 로그인, 서버, 결제
- 외부 3D 모델, 텍스처 이미지 파일
- 복잡한 퀘스트 체인

## 8. 아이가 참여하는 포인트
개발할 때 아이한테 직접 물어보고 결정할 것들 — 이게 이 프로젝트의 진짜 목적:
- 캐릭터 이름과 색깔
- 우리 집을 어디에 지을지, 무슨 색으로 할지
- NPC들이 하는 말 대사
- 성의 지붕 색
- 다음에 뭘 추가할지

## 9. 파일 구조
```
number-village/
├── index.html            # importmap + UI 오버레이 + 캔버스
├── CLAUDE.md             # Claude Code 작업 규칙
├── docs/기획안.md         # 이 문서
└── src/
    ├── main.js           # 부팅, 씬, 게임 루프, 화면 전환
    ├── characters.js     # 캐릭터 데이터 + 3D 생성 팩토리 ★핵심
    ├── world.js          # 마을 지형·건물 생성
    ├── player.js         # 플레이어 조작 + 3인칭 카메라
    ├── npcs.js           # NPC 배회·이름표·말풍선
    ├── ui.js             # 캐릭터 선택 / 도감 / 모바일 컨트롤
    └── save.js           # localStorage 저장
```
