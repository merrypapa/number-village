# 넘버블럭스 월드 — 진행 상황

> 두 번째 게임. 코드는 `numberblocks/` 폴더에 따로 있다.
> 첫 화면(`index.html`)에서 **시작하기 → 어떤 게임을 할까? → 넘버블럭스 월드**로 들어온다.
> 티니핑 월드(기존 숫자마을)는 `docs/진행상황.md`를 본다.

## 현재 상태
- ✅ **Phase 0** 무대 준비 — 들판·하늘·조명, 숫자 블록 탑 1~10 (누르면 숫자를 말하고 통통 튄다),
  "◀ 월드 고르기" 버튼 → `numberblocks/src/main.js`

## 다음에 할 것
- ⬜ 새 게임 기획 정하기 (아빠와 아이가 같이) → `docs/넘버블럭스-기획안.md`에 적는다
- ⬜ 캐릭터는 **오리지널 디자인**으로 만든다 (CLAUDE.md 규칙 3)

## 폴더 규칙
- 새 게임 코드는 `numberblocks/src/` 안에만 둔다. 티니핑 월드 코드(`src/`)와 섞지 않는다
- 티니핑 월드 것을 가져다 쓰고 싶으면 `../../src/파일.js`로 import 한다 (복사하지 않는다)
