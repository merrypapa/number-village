# 넘버블럭스 월드 — 진행 상황

> 두 번째 게임. 코드는 `numberblocks/` 폴더에 따로 있다. 기획은 `docs/넘버블럭스-기획안.md`.
> 첫 화면(`index.html`)에서 **시작하기 → 어떤 게임을 할까? → 넘버블럭스 월드**로 들어온다.
> 티니핑 월드(기존 숫자마을)는 `docs/진행상황.md`를 본다.

## 현재 상태
- ✅ **Phase 0** 월드 고르기 화면 + 빈 무대
- ✅ **Phase 1** 티니핑 월드 마을을 그대로 빌려 쓰기 (`buildWorld(scene, { artHouse })`, 요정 진열대·집주인·점원 없이)
- ✅ **Phase 2** 숫자 블록 친구 1~100 — 처음엔 코드 도형으로 만들었다가, **원작 표를 잘라낸 그림(스프라이트)** 으로 바꿈
  (`assets/numberblocks/`, `blocks.js`, `book.js`). `registerBuilder('numberblock')`로 characters.js에 끼워 넣음
- ✅ **Phase 3** 밤 (`night.js`) — 별·달·내 주변 불빛·안개, 이기면 아침
- ✅ **Phase 4** 친구 구하기 (`rescue.js`) — 1~99 흩뿌리기, 몸이 닿으면 저절로 구하기(+두드리기), 여러 명 연달아 구하기, 🧭 나침반, localStorage 저장
- ✅ **Phase 5** 📖 도감 (`book.js`) — 한 페이지 10명, 그림·이름·짧은 소개, 못 찾은 친구는 `?`, 누르면 자세한 소개말
- ✅ **Phase 6** 🔢 숫자의 집 (`number-house.js`) — 그림의 집 자리, 넓은 방, 구한 친구들이 돌아다님
- ✅ **Phase 7** 🌙 달님 (`moon.js`) + 🌀 팽이치기 (`top-game.js`) — 슥슥 그어서 줄로 치기, 이기면 낮 + 친구들이 마을로

- ✅ **추가** 🏃 오른쪽 아래 버튼 = 달리기 켜기/끄기 (손인사 대신). 엔터는 인사
- ✅ **추가** 🔧 관리자 모드 — 스토리 화면 아래 작은 글씨, 비밀번호 `0000` (`main.js` 맨 위 `ADMIN_PW`).
  달님이 바로 게임을 받아주고 HUD에 🌀 팽이치기 바로가기가 뜬다
- ✅ **추가** 대표 아이콘 `assets/icon.svg` (+ png 32/180/192/512), `manifest.webmanifest` — 브라우저 탭·홈 화면 아이콘
- ✅ 100도 원작처럼 눈 하나

- ✅ **고침** 숫자의 집에 구한 친구가 안 나오던 것 — 문 이름('art')과 공간 이름('numbers')이 달라서. 공간 이름으로 본다 (`travel.js`)
- ✅ **고침** 말을 타거나 점프 중이면 바로 옆 친구도 안 구해지던 것 — 거리를 땅 위(x, z)로만 잰다. 말 탈 때는 닿는 거리 3.4
- ✅ **추가** 숫자의 집 문 앞·창가 등불 3개 (`night.addHouseLight`) — 밤에도 멀리서 보인다. 낮이 되면 꺼진다

- ✅ 100을 코드로 만든 3D 모델도 시험해 봤지만 원작 느낌이 덜해서 뺐다 → 전부 그림 블록으로 통일
- ✅ **고침** 가운데 안내글(toast)이 단어 중간에서 줄바꿈되던 것 — 띄어쓰기에서만 줄을 바꾸고 화면 폭에 맞게 글씨를 줄인다 (티니핑 월드도 같이)

## 티니핑 월드 쪽에 손댄 것 (동작은 그대로)
- `src/characters.js` `registerBuilder()` 추가
- `src/castle-interior.js` `opts.gallery === false`면 진열대 생략
- `src/village-buildings.js` `makeArtHouseBuilding('numbers')` = 숫자의 집 겉모습
- `src/world.js` `buildWorld(scene, { artHouse })`
