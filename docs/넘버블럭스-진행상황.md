# 넘버블럭스 월드 — 진행 상황

> 두 번째 게임. 코드는 `numberblocks/` 폴더에 따로 있다. 기획은 `docs/넘버블럭스-기획안.md`.
> 첫 화면(`index.html`)에서 **시작하기 → 어떤 게임을 할까? → 넘버블럭스 월드**로 들어온다.
> 티니핑 월드(기존 숫자마을)는 `docs/진행상황.md`를 본다.

## 현재 상태
- ✅ **Phase 0** 월드 고르기 화면 + 빈 무대
- ✅ **Phase 1** 티니핑 월드 마을을 그대로 빌려 쓰기 (`buildWorld(scene, { artHouse })`, 요정 진열대·집주인·점원 없이)
- ✅ **Phase 2** 숫자 블록 친구 1~100 (`block-data.js`, `blocks.js`) — `registerBuilder('numberblock')`로 characters.js에 끼워 넣음
- ✅ **Phase 3** 밤 (`night.js`) — 별·달·내 주변 불빛·안개, 이기면 아침
- ✅ **Phase 4** 친구 구하기 (`rescue.js`) — 1~99 흩뿌리기, 두드리기/구하기 버튼, 🧭 나침반, localStorage 저장
- ✅ **Phase 5** 📖 도감 (`book.js`) — 10×10, 못 찾은 친구는 `?`, 누르면 소개말
- ✅ **Phase 6** 🔢 숫자의 집 (`number-house.js`) — 그림의 집 자리, 넓은 방, 구한 친구들이 돌아다님
- ✅ **Phase 7** 🌙 달님 (`moon.js`) + 🌀 팽이치기 (`top-game.js`) — 슥슥 그어서 줄로 치기, 이기면 낮 + 친구들이 마을로

## 티니핑 월드 쪽에 손댄 것 (동작은 그대로)
- `src/characters.js` `registerBuilder()` 추가
- `src/castle-interior.js` `opts.gallery === false`면 진열대 생략
- `src/village-buildings.js` `makeArtHouseBuilding('numbers')` = 숫자의 집 겉모습
- `src/world.js` `buildWorld(scene, { artHouse })`

## 다음에 할 것 (아이 반응 보고)
- ⬜ 친구마다 표정·소품 더 다르게 (지금은 4 안경·7 무지개·8 팔 8개만)
- ⬜ 밤 마을에 가로등 몇 개 (너무 깜깜하면)
- ⬜ 팽이치기 난이도 조절 (`top-game.js` 맨 위 값)

## 폴더 규칙
